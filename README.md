# ASCII-LUBANG-HITAM

## Run in a Codespaces browser

Install the dependencies and start the web server:

```bash
python -m pip install -r requirements.txt
python webapp.py
```

In VS Code, open the **Ports** tab, find port `8000`, and choose **Open in Browser**.
The animation is streamed to the browser. Stop the server with `Ctrl+C`.

To open the native Pygame window on a computer with a desktop, run:

```bash
python lubanghitam.py
```
